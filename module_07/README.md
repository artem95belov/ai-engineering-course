# Модуль 7 — LLM-агенты и tool use (занятия 13–14)

Агент на GigaChat: модель получает задачу и набор инструментов, а порядок
действий выбирает сама — цикл ReAct «мысль → действие → наблюдение».
Read-инструменты агент вызывает свободно, write-инструмент `create_ticket` —
только после явного подтверждения человеком. Занятие 14 - проверка агентного
поведения на пяти контрольных сценариях.

## Установка

```powershell
# из корня репозитория, с активированным .venv
pip install -r module_07/requirements.txt
```

Модели эмбеддингов и Docker в этом модуле не нужны: поиск по документации
закрывает заглушка `rag_stub.py`, инструменты корпоративных систем —
`tools_stub.py`. Настоящий RAG Модуля 4 подключается мостом `rag_adapter.py` —
одна строка импорта в `tool_use_native.py` (нужен выполненный `module_04`
с собранным индексом; сверено живым прогоном 22.08.2026). MCP-сервер
Модуля 6 живёт на собственном реестре (PUMP-07 и ещё 4 единицы) и другой
сигнатуре `create_incident` — прямой замены для `tools_stub.py` нет,
инструменты корпоративных систем остаются на заглушке (сверено с готовым
Модулем 6 01.09.2026).

## Запуск

```powershell
cd module_07
python tools_stub.py              # посмотреть, как отвечают инструменты (без ключей)
python rag_stub.py                # посмотреть, как отвечает заглушка базы (без ключей)
python tool_use_native.py         # Занятие 13: агент на двух демо-задачах (нужен ключ GigaChat)
python agent_eval.py              # Занятие 14: 5 сценариев + RESULTS.md (нужен ключ)
```

Пин `gigachat==0.2.1` — сознательный, тот же, что в module_03/module_05:
свежие версии SDK (0.2.3+) переключают адрес API на новый `api.giga.chat`,
где нет алиаса «GigaChat», которым пользуются Модули 1–3. Один общий `.venv`
курса — значит, версия SDK одна на все модули. Модель всё равно указываем явно.

## Troubleshooting

- **`404 No such model`** — модель в коде указывается явно: `GigaChat-2`.
  Алиаса «GigaChat» на новом API больше нет.
- **Агент не вызывает `create_ticket`** — почти всегда дело в описании
  инструмента (TODO 1): модель решает по докстрингу. Проверь, что в нём
  сказано, ЧТО делает инструмент и КОГДА его вызывать.
- **Агент крутится до лимита шагов** — не сделано условие остановки (TODO 4):
  пустой `msg.tool_calls` означает финальный ответ.
- **В ответе агента LaTeX (`$...$`)** — правило «отвечай без LaTeX» стоит
  в системном промпте; если убрать, GigaChat-2 иногда включает разметку.
- **`GIGACHAT_CREDENTIALS не найден`** — файл `.env` лежит в корне репозитория
  (не в module_07), внутри Authorization key, а не Client ID.
- **`ImportError: rag_stub`** — запускай скрипты из папки `module_07`,
  а не из корня репозитория.
